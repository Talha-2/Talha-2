## Projects

**[Veyra](https://veyra-pi-one.vercel.app/)**
AI front desk for clinics. Answers patient calls and messages, and books appointments directly in the practice's EHR.
`LiveKit` `Deepgram` `FastAPI` `Next.js`

**[Quorum](https://github.com/Talha-2/Quorum)**
Multi-agent research workbench. Turns a brief and its documents into a knowledge graph, then runs a structured debate between LLM personas that ends in a consensus report.
`FastAPI` `LangChain` `Next.js` `d3`

**[PhotoLoRA](https://github.com/Talha-2/PhotoLoRA)**
LoRA fine-tuning of Stable Diffusion XL on a single 16 GB GPU, evaluated with CLIP score and FID/KID, and served through a batched FastAPI endpoint.
`PyTorch` `Diffusers` `PEFT` `FastAPI`

**[TinyDiffusion](https://github.com/Talha-2/TinyDiffusion)**
DDPM and DDIM implemented from the papers in plain PyTorch, with no diffusion libraries. Compares linear and cosine noise schedules on CIFAR-10.
`PyTorch`

**[sloplint](https://github.com/Talha-2/sloplint)**
Catches the checkable problems AI-written code ships with: hallucinated packages, placeholder code and tests that can't fail. CLI, GitHub Action and agent skills.
`Node.js`

**[SpeakWell](https://talha-razzaq.netlify.app/FYP_Thesis.pdf)**
Final year project. Phoneme recognition that identifies which sounds a patient says wrong, for speech pathologists at NIRM Islamabad. Runs offline on a Raspberry Pi.
`Kaldi` `C++` `Python`

**[NUST coursework](https://github.com/Talha-2/NUST)**
